Basic Calculator App

This project is a simple calculator application built using Python. It runs in the command line and allows users to perform basic arithmetic operations like addition, subtraction, multiplication, and division. The project was created to practice Python fundamentals such as functions, loops, conditionals, and user input handling.

It has many "Features" like:
- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Exit option
  Press RUN to run the given code
